# DevOps Bootcamp Final Project

End-to-end DevOps infrastructure project implemented using:

- AWS
- Terraform
- Ansible
- Docker
- Amazon ECR
- Prometheus
- Grafana
- Cloudflare
- GitHub Actions

## Architecture

The project will provision an AWS environment containing:

- VPC
- Public subnet
- Private subnet
- Internet Gateway
- NAT Gateway
- Security Groups
- Web Server
- Ansible Controller
- Monitoring Server
- Amazon ECR
- Terraform remote state in Amazon S3
